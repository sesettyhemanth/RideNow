🚗 Bike, Scooter & Car Rental System

📌 Project Overview

The Bike, Scooter & Car Rental System is a web-based application that allows users to rent bikes, scooters, and cars online. Users can explore available vehicles, view vehicle details, book vehicles, manage their profiles, and check their booking history through a user-friendly interface.

The main objective of this project is to make vehicle rental simple, convenient, and accessible through an online platform.

🎯 Objectives

Provide an easy-to-use vehicle rental platform.

Allow users to browse bikes, scooters, and cars.

Display vehicle details and rental prices.

Enable users to book vehicles online.

Allow users to manage their profiles and bookings.

Provide booking history, wishlist, and notification features.

Create a responsive interface for desktop and mobile devices.

⚙️ Installation and Setup

Step 1: Clone the Repository

git clone YOUR_GITHUB_REPOSITORY_URL

Replace YOUR_GITHUB_REPOSITORY_URL with your actual GitHub repository URL.

Step 2: Open the Project

cd RideNow

Step 3: Install Dependencies

npm install

Step 4: Start the Development Server

npm run dev

Step 5: Open in Browser

Open the local URL displayed in your terminal, usually:

http://localhost:5173/
